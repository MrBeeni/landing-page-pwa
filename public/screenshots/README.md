# PWA Screenshots

For app store listings and install prompts, add screenshots:

## Desktop Screenshot (desktop.png)
- Recommended size: 1280x720 or 1920x1080
- Shows the portfolio on a desktop/laptop view
- Capture the hero section and services

## Mobile Screenshot (mobile.png)
- Recommended size: 750x1334 (iPhone) or 1080x1920 (Android)
- Shows the portfolio on a mobile device
- Capture the full single-page layout

You can take these screenshots after deploying the site or using browser dev tools.
