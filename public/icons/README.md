# PWA Icons

To make this PWA production-ready, you need to add app icons in the following sizes:

- icon-72x72.png
- icon-96x96.png
- icon-128x128.png
- icon-144x144.png
- icon-152x152.png
- icon-192x192.png
- icon-384x384.png
- icon-512x512.png

You can generate these icons from a single source image (ideally 512x512px) using:
- https://realfavicongenerator.net/
- https://www.pwabuilder.com/imageGenerator
- Or any image editing tool

## Icon Design Guidelines

1. Use a simple, recognizable logo or initials (e.g., "MM" for Muhammad Mubeen)
2. Ensure the icon works well on both light and dark backgrounds
3. Keep the design centered with some padding (safe zone)
4. Use your primary brand color (#10b981 - green)
5. Make it maskable-safe (important content within 80% of the canvas)
